Android, iOS, Nintendo 3DS and the Aroma receiver are included in this release.

- Gyro pointing in Wii Remote and MotionPlus modes, with CENTER calibration,
  adjustable sensitivity/smoothing and touch override.
- Pro and Classic Controller modes, players 1–4 on phones, and portrait /
  landscape Wii Remote controls.
- Customizable layouts, import/export and appearance settings.

Choose your platform's package below. Put the Aroma `.wps` file in
`wiiu/environments/aroma/plugins/` on the Wii U SD card and restart the console.

The iOS IPA requires an active jailbreak and AppSync Unified. MotionPlus and
live game compatibility remain experimental. The 3DS client uses player 2.
See the README for setup, feature details and testing limits.

`SHA256SUMS.txt` and `release.json` contain the package checksums.
